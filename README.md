# Autoethnography Website (Static)

This ZIP contains a static website:

- `index.html` – the main page
- `styles.css` – styles and color palette
- `assets/` – placeholder images used by the layout

## How to use
1. Download and unzip.
2. Open `index.html` in your browser, or upload everything to a host (Adobe Portfolio, GitHub Pages, or Wix).
3. Replace images in `assets/` with your own (keep the same filenames to avoid editing CSS).
4. Customize text directly in `index.html`.

## Image replacement tips
Use these keywords in Adobe Express or stock libraries to find visuals:
- Indiana Avenue street sign, urban street background
- Map of Indianapolis; Haughville
- Railroad worker; duplex house; Frog's Candy Store
- Lens overlay; mirror reflection; identity collage
- Bridge/path graphic; microscope; justice scales
- Qualitative vs quantitative; papers; blueprint; worldview; coding notes
- Abstract vs introduction; sunrise horizon
